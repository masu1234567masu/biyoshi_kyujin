## 4. 自動投稿システムに必要な要件（未着手・Claude Codeで構築予定）

### 課題
- Claude.ai（このチャット）で生成した画像は、Claudeのサンドボックス内のローカルファイルであり、外部から読み込める「公開URL」ではない
- Metricoolの`createScheduledPost`（投稿API）は、画像を**公開URL**として受け取る必要がある（`media`フィールド）
- Claude.aiのサンドボックスはネットワーク接続が無効化されており、直接クラウドストレージにアップロードするAPIコールができない
- ブラウザ拡張機能（Claude in Chrome）経由でのGoogle Driveアップロードも試みたが、権限エラー（Permission denied）で接続できなかった

### 構築したいシステムの流れ
1. 生成した画像ファイル（JPEG、8枚程度/投稿）を、**Google Driveの特定フォルダにプログラムからアップロード**
2. アップロードしたファイルの**公開共有リンクを取得**
3. そのURLとキャプション文を使い、**Metricool API（createScheduledPost）を呼び出して投稿を作成**
4. Metricool側で「Google Driveと連携している場合、Drive/DropboxのURLは自動でアップロードされる」という仕様があるとのことなので、この挙動を利用する想定

### 必要な認証・設定（未実施）
- **Google Cloud プロジェクト作成**
- **Google Drive API の有効化**
- **サービスアカウントの作成・認証キー（JSON）発行**
- 増田優作のGoogle Driveの特定フォルダに、そのサービスアカウントへの編集権限を付与
- **Metricool APIキーの発行**（Metricoolの設定画面から取得可能）
- 上記キー類の安全な保管方法（環境変数、シークレットマネージャー等）の検討

### Metricool API仕様メモ（ツール定義から抜粋）
- `createScheduledPost`：`blogId`（=6852890）、`date`（ISO 8601）、`info`（JSON文字列）が必須
- `info`内の`media`：画像の公開URLの配列。Google Drive/DropboxのURLは自動アップロードに対応（要Google Drive連携設定）
- `info`内の`providers`：`[{"network":"instagram"}]`
- `info`内の`instagramData`：`{"type":"POST"}` （カルーセル投稿の場合も type は POST でよい）
- `text`：キャプション本文（必須）
- タイムゾーンは `Asia/Tokyo`（getBrandSettingsで確認済み）

## 5. コンテンツ制作ルール（画像デザイン・投稿運用）

### デザインルール
- 見出し：Noto Serif CJK（明朝系）／本文：Noto Sans CJK
- 色分け：雇用＝グレー系（RGB目安 95,100,112）、フリーランス／面貸し＝ロゴ赤系（RGB目安 178,60,38）、業務委託＝グレー系
- レイアウト：テキスト中央寄せ、コンテンツ全体を画面内で上下中央配置（余白均等）
- 文字サイズ：本文36〜40px、見出し50〜58px、強調数字は最大90px程度
- 縦位置の決め方：各行の高さを計算して積み上げる方式（手動の決め打ち数値ではなく、フォントサイズ×行数から動的に算出し、重なり・ズレを防ぐ）
- 1枚目の対比構造（例：雇用 VS フリーランス）は各要素を均等間隔で配置
- スライド構成：1枚目＝ベージュレザーテクスチャ写真 or 店内写真の背景、2枚目以降＝ロゴウォーターマーク入りグレー背景
- 絵文字は画像内では文字化け（✕表示）するため使用しない。キャプション本文では絵文字使用OK

### キャプション作成ルール
- ハッシュタグは必ず付ける（Instagram表示上限に合わせて**5個まで**）
- 基本セット：#美容師求人 #フリーランス美容師 #面貸し美容師 #美容師の働き方 #中目黒美容室 #美容師転職（投稿内容に応じて5個を選択）

### コンテンツの立ち位置（重要・厳守）
- アカウントは長期的にメディア資産として育てる方針
- 投稿本文は**中立的な情報発信**（どのサロンにも当てはまる、フリーランス美容師全般に役立つ内容）にする
- **piece201への言及は、最後のスライド・キャプションの締めのみ**に留める（「piece201ではこうサポートしています」等の自社アピールを本文中で挟まない）

### 業界用語の正確な区別（重要）
- **面貸し**：自分の指名客のみ対応、新規客なし、完全歩合60%〜が相場、自由出勤制
- **業務委託**：サロンが新規集客（ホットペッパー等）を担う代わりに時間拘束あり、歩合は新規40%・指名50%程度
- **雇用**：固定給＋指名歩合10〜20%程度、時間拘束が最も大きい
- piece201の契約形態は「面貸し」（新規集客はなし、指名売上歩合70%）

### 3本目：面貸し vs 業務委託の違い
集客・拘束時間の違いを解説。「10年やってわかった、正直な話」として、業務委託の「悪いところ取りになりやすい」実情、面貸しは最初の2〜3ヶ月厳しくなりがちで既存客40〜50万円の土台があると安心、という本音を掲載。7枚構成。投稿済み。

### 4本目：面貸し美容師によくある悩みTOP5
①集客できるか不安 ②技術向上しにくい ③収入が不安定 ④税務・確定申告がわからない ⑤契約トラブル、の5項目を一覧化。7枚構成。投稿済み。

### 5本目：面貸し美容師は、一人社長
美容師業務・バックオフィス業務（予約・売上・カルテ管理）・セルフマネジメントの3役をこなす必要がある、という内容。「一人社長を体現できる人は伸びる、コスパ・タイパだけで選ぶと長続きしない」という本音、締めで「同じ境遇の仲間を作る」「piece201には面貸しスタイリストが多数在籍」に言及。7枚構成。投稿済み。

### 6本目：フリーランス美容師になったら、まず知るべき税金の話
①開業届（出さなくても罰則はないが税制優遇のため必要）②所得税・確定申告（最初の1年は自分でやってみて税理士業務を理解する価値の話）③経費とは何か ④知らないと損すること（消費税・住民税等）。ハッシュタグに#確定申告 #一人社長 を追加。7枚構成。投稿済み。

### 7本目：フリーランスの保険と年金の話
①美容師国保組合（東京美容国民健康保険組合＝事業所所在地・居住地の両方が東京都・神奈川・千葉・埼玉・茨城・山梨のエリア内である必要がある、という正確な加入条件）②国民健康保険 ③社会保険（法人化以外にも、個人事業主のまま加入できるサービスもある、というサービス名は伏せた一般情報）④国民年金の手続き（自動切り替えではなく退職日翌日から14日以内に市区町村役場で手続きが必要）⑤国民年金の金額・将来性（少子高齢化への率直な言及）。8枚構成。**画像・キャプションは完成済みだが、Metricool経由の自動投稿がまだできておらず、投稿は未実施**。
