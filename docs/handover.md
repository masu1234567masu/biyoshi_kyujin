## 1. プロジェクトの背景と目的

増田優作氏（美容室piece201のオーナーの一人）が、以下の目的でInstagram求人アカウントを立ち上げた。

- **短期目的**：piece201（中目黒）のフリーランス（面貸し）スタイリスト採用
- **長期目的**：将来的にフリーランス美容師向けの情報メディアとして育て、他サロンの求人も扱えるアカウントに成長させる
- **将来の展望（当初構想）**：3段階のロードマップ
  1. フェーズ①（現在）：piece201の採用ツールとしてSNS発信（自社採用は職業紹介事業の規制対象外）
  2. フェーズ②：知り合いの美容室オーナーへの無償紹介（金銭を伴わない口利きの範囲）
  3. フェーズ③（将来）：厚生労働大臣の「有料職業紹介事業許可」を持つ知人と組み、成果報酬を取る本格的な人材紹介事業化。増田氏は候補者集め・情報収集を担当し、免許保有者が斡旋・成約プロセスを担当する分担

## 4. アカウント設計の経緯（考え方の変遷）

このチャットでは、以下のような紆余曲折を経て現在の設計に至った。参考として経緯を残す。

1. 当初は「全国のいろんな美容室に求人が届くように」という発想からスタートし、Instagram・Threads・Xの3媒体構成、全国展開のロードマップを検討した
2. その後、「まずは中目黒piece201のために、まずは東京都内・20代スタイリストに絞ろう」と方針転換
3. さらに「30代にも広げる」「業務委託ではなく面貸し」「指名売上70%」など募集条件を確定
4. プロフィール・アカウント名を検討する中で、一時「最初から複数サロンを扱う求人メディアとして作り、piece201はその中の1投稿として出す」方針になりかけたが、「フォロワーゼロの段階で複数サロン扱う体裁だと、求人が1件しかないギャップが不自然」という理由で撤回
5. **最終決定**：アカウント名は将来の拡張を見据えた「フリーランス美容師の働き方&求人」のままにしつつ、当面はpiece201専用の求人アカウントとして運用し、他サロンの求人が実際に増えたタイミングで自然に「複数サロン扱う求人メディア」へ育てていく、という段階的な方針に着地した
6. 既存のpiece201集客用Instagram（フォロワー1,510人、@piece201.masudayusaku）を求人用に転用する案も出たが、「本業の集客チャネルを毀損するリスクがある」という理由で見送り、完全に新規アカウントとして「フリーランス美容師の働き方&求人」（@freelance_biyoshi_kyujin）を立ち上げた
7. コンテンツの立ち位置についても議論があり、「アカウント全体をpiece201の宣伝にすべきか」という問いに対し、「長期的にメディア資産を育てたい」という増田氏の意向から、**投稿本文は中立的な情報発信に徹し、piece201への言及は最後のスライド・キャプションの締めのみに留める**という現在のルールに確定した

## 6. デザイン・運用ルール（確定・厳守事項）

### 画像デザインルール
- 見出し：Noto Serif CJK（明朝系）／本文：Noto Sans CJK
- 色分け：雇用・業務委託＝グレー系（RGB目安 95,100,112）、フリーランス・面貸し＝ロゴ赤系（RGB目安 178,60,38）
- テキストは中央寄せ、コンテンツ全体を画面内で上下中央配置し、余白を均等にする
- 文字サイズは大きめ（本文36〜40px、見出し50〜58px、強調数字は最大90px程度）
- 縦位置は各行の高さを計算して積み上げる方式で決定する。手動の決め打ち数値による配置は禁止（重なり・ズレの原因になったため）
- 1枚目の対比構造（例：雇用 VS フリーランス）は各要素を均等な間隔で配置する
- スライド構成：1枚目＝ベージュレザーテクスチャ写真または店内写真、2枚目以降＝ロゴウォーターマーク入りグレー背景
- **絵文字は画像内に描画すると「✕」の文字化けを起こすため使用しない**（フォントに絵文字グリフが含まれていないため）。キャプション本文中の絵文字はInstagram側で正常表示されるため問題なく使用する

### キャプション作成ルール
- ハッシュタグは必ず付ける。**Instagramの表示上限に合わせて5個まで**（このルールは4本目制作中に確定したため、1〜3本目のキャプションには6個のハッシュタグが残っている。今後修正するかは未定）
- 基本セット：#美容師求人 #フリーランス美容師 #面貸し美容師 #美容師の働き方 #中目黒美容室 #美容師転職（の中から5個を状況に応じて選択）
- 投稿内容に応じて特殊なハッシュタグ（例：6本目は#確定申告 #一人社長）を通常セットの代わりに使うこともある

### コンテンツの立ち位置（最重要ルール）
- アカウントは長期的にメディア資産として育てる方針
- 投稿本文は**中立的な情報発信**（どのサロンにも当てはまる、フリーランス美容師全般に役立つ内容）にする
- **piece201への言及は、最後のスライド・キャプションの締めのみ**に留める。「piece201ではこうサポートしています」等の自社アピールを本文中で挟まない
- 具体的な売上・年収などの生々しい数字は、増田氏個人のものとして公開しない方針（例：原宿時代の個人指名売上100万円などは投稿に出さない）

### 業界用語の正確な区別（コンテンツの正確性に直結する重要事項）
- **面貸し（ブースレンタル）**：自分の指名客のみ対応、新規客なし、サロンの広告費がかからない分、完全歩合60〜70%が相場。時間拘束なし・自由出勤制
- **業務委託**：サロンが新規集客（ホットペッパー等）を担う代わりに時間拘束あり、歩合は新規40%・指名50%程度
- **雇用**：固定給＋指名歩合10〜20%程度、時間拘束が3形態の中で最も大きい（営業時間外の練習・後輩指導・休日のコンテスト出場なども業務の一部になりやすい）
- piece201の契約形態は「面貸し」（新規集客はなし、指名売上歩合70%、自由出勤制）

【雇用 vs フリーランス、一番の違いは?】

美容師の働き方には、雇用・業務委託・面貸しの3種類があります。
まずは「雇用」と「フリーランス(業務委託・面貸し)」の違いから。

①報酬
雇用は固定給+指名歩合10〜20%程度。毎月安定した金額が保証されます。

フリーランスは出勤日・時間を自分で決められる自由出勤制。仕事以外の時間の使い方も含めて裁量が大きくなります。

③集客・社会保障
雇用は集客不要、社会保険などの保障もあります。
フリーランスは集客も自己責任(面貸し・業務委託で度合いは異なります)。社会保障もありません。その代わり、報酬と時間は自分のもの。

  1. Facebookアプリで新規にFacebookページ「フリーランス美容師の働き方&求人」を作成（カテゴリ：美容室）
  2. **PCブラウザで**Facebookにログインし、対象のFacebookページに切り替え
  3. ページの「設定」→「コネクテッドエクスペリエンス」→「リンク済みのプロフィール」→「アカウントを追加」→「Instagramアカウントを追加」から連携
  4. これでFacebookページとInstagramのリンクが成立（「Instagramがリンクされました」と表示）

### Metricool API仕様メモ
- `createScheduledPost`：`blogId`（=6852890）、`date`（ISO 8601）、`info`（JSON文字列）が必須
- `info`内の`media`：画像の公開URLの配列。Google Drive/DropboxのURLは自動アップロードに対応（Metricool側でGoogle Drive連携の設定が必要）
- `info`内の`providers`：`[{"network":"instagram"}]`
- `info`内の`instagramData`：`{"type":"POST"}`（カルーセル投稿でも type は POST）
- `text`：キャプション本文（必須）
- `getBestTimeToPostByNetwork`で、曜日・時間帯ごとのエンゲージメント予測値が取得できる（このアカウントでは水曜10時台が最高値）

### 今後の運用フロー（確立済み）
1. Claude.ai/Claude Codeで画像とキャプションを作成（`scripts/generate_all_slides.py`にpost関数を追加）
2. `python3 scripts/drive_upload.py <画像ファイル...>` でDriveにアップロードし、公開URLを取得（出力は`ファイルID<TAB>URL`の形式）
3. Metricool MCPの`createScheduledPost`で、それらのURLとキャプションを渡して予約投稿を作成
4. レスポンスの`media`が`static.metricool.com`のURLに変換されていることを確認できたら、Metricool側への取り込みは完了しているので、Drive容量節約のため元ファイルを削除する：`python3 scripts/drive_upload.py delete <ファイルID...>`
5. 「自動で投稿して」と言われたタイミングで、上記2〜4をClaude Codeが実行する運用

## 12. このチャットで学んだ教訓・失敗談（今後同じ轍を踏まないために）

- **画像内の絵文字は文字化けする**。Noto Sans/Serif CJKフォントには絵文字グリフが含まれていないため、PIL/Pillowで描画すると「✕」になる。画像には絵文字を使わず、キャプション本文（Instagram側でネイティブ描画される部分）でのみ使用する
- **手動の決め打ち座標での要素配置は、文字サイズを変更するたびにズレや重なりを起こす**。フォントサイズから行の高さを計算し、要素を積み上げていく方式で配置することで再現性のあるレイアウトになる
- **中央寄せ・上下中央配置・大きめ文字**という基本方針を最初から徹底しないと、後から全スライドを作り直す手間が発生する（実際に2本目の途中でこの方針転換が発生し、1本目に遡って修正が必要になった）
- **Metricoolのモバイル向けInstagram連携UIは不安定**。エラーが出たら、まずPCブラウザからの操作に切り替えるとよい
- **Claude（このチャット環境）は外部への直接アップロードができない**。ネットワークが無効化されたサンドボックス環境のため、画像を公開URL化する処理は、ブラウザ拡張機能経由か、別途構築する外部プログラム（Claude Codeでの実装等）に頼る必要がある
- **業界用語（面貸し・業務委託・雇用）の違いは、必ず事実確認してから投稿内容に反映する**。当初は「フリーランス」と一括りにしていたが、増田氏からの訂正で歩合率・拘束時間・集客主体が明確に異なることが判明し、複数の投稿で表記統一の手戻りが発生した
- **具体的な数字（開業届の罰則有無、国民年金の手続き期限、美容国保の加入条件など）は、必ずWeb検索で裏取りしてから投稿に反映する**。増田氏の記憶ベースの情報とファクトが食い違うことがあったため（例：国民年金は自動切り替えではなく14日以内の手続きが必要、という点は検索で確認して訂正した）
